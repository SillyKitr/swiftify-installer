# Security policy

This project is an unofficial community installer and handles downloads,
archives, filesystem changes, shortcuts, and Windows registry metadata.

## Reporting a vulnerability

If GitHub Security Advisories are enabled for this repository, please use the
private **Report a vulnerability** option on the repository's **Security**
tab. Do not disclose exploitable details in a public issue.

If private reporting is not available, open a public issue only with enough
information to request private contact, and avoid including credentials,
personal data, or a working exploit. Maintainers will determine the safest
way to continue the report.

Please include the affected version or commit, operating system, impact,
reproduction steps, and logs or screenshots where safe to share.
